# Paper test sonuçları

Bu dal GitHub Actions `paper-test` iş akışı tarafından otomatik doldurulur (gerçek emir YOK, sadece simülasyon).

- `SUMMARY.md` — tüm çalıştırmaların kümülatif özeti (varyant bazında PnL, PnL / alım, kazanma oranı)
- `runs/<tarih>_<run id>/` — her çalıştırmanın raporları, işlem (fill) listeleri ve log'u
